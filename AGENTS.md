# AGENTS.md — go-wayland

Pure Go (no CGO) Wayland client library: `github.com/vcaesar/go-wayland`, a fork of rajveermalviya/go-wayland. Protocol packages are generated from XML.

## Commands

The repo has **three Go modules**: `.` (library), `examples/` (uses `replace => ../`) and `cmd/go-wayland-scanner/`. A `./...` run from the root does not cover the other two. CI runs this for each module:

```sh
for mod in . examples cmd/go-wayland-scanner; do
  (cd "$mod" && go build ./... && go vet ./... && go test -count=1 ./...)
done
gofmt -l .                                   # CI fails if this prints anything
golangci-lint run --config "$PWD/.golangci.yml" ./...   # v2 config; run inside each module dir with the root config
```

- Single test: `go test -count=1 -run TestArrayRequestWire ./unstable/text-input-v3/`
- CI uses `CGO_ENABLED=0`. Go versions tested: the `go.mod` minimum (1.26.0) and 1.27.x.
- All three modules declare `go 1.26.0`. Bump them together: `examples` pulls the root's deps through `replace`, so after changing the root `go.mod`, run `go mod tidy` in `examples/`. Otherwise its build fails with "updates to go.mod needed".
- Write modern Go (range-over-int, `min`/`max`, `strings.SplitSeq`, `any`). `go fix -diff ./...` in each module should print nothing, except in generated files. Fix those in the scanner instead.
- Cross-build check (CI): `GOOS=freebsd GOARCH=amd64 go build ./...` (also openbsd, netbsd, darwin and several linux arches). Keep code Unix-portable and use `golang.org/x/sys/unix`, not Linux-only syscalls.

## Code generation

- Every protocol package has a `doc.go` containing a `//go:generate go run github.com/vcaesar/go-wayland/cmd/go-wayland-scanner -pkg … -prefix … -suffix … -o X.go -i <URL>` line. The output file starts with `// Code generated by go-wayland-scanner. DO NOT EDIT.`
- **Never hand-edit generated files**: `client/client.go` and the protocol `.go` files under `stable/`, `staging/`, `unstable/`, `wlr/` and `external/`. Change `cmd/go-wayland-scanner/scanner.go`, then regenerate every package and commit the output. The CI `generate` job regenerates everything and fails on any diff.
- The scanner lives in its own module, so CI builds it once and runs it for each `doc.go` instead of calling `go generate`. Do the same locally (requires network: inputs are gitlab.freedesktop.org URLs):
  ```sh
  (cd cmd/go-wayland-scanner && go build -o ../../test/tmp/scanner .)
  # then run the "Regenerate" loop from .github/workflows/go.yml with that binary
  # (test/tmp/regen.sh does this if it exists locally; test/tmp is gitignored)
  ```
  The root `./generate` script needs GNU `parallel` and forwards only `$1`. Prefer the CI loop.
- The scanner formats output with `gofumpt` (ExtraRules) and `go/doc.Synopsis`. Swapping out the deprecated `doc.Synopsis` changes the output, so do it together with a regen (lint excludes SA1019 there on purpose).
- When an interface-typed argument comes from another protocol, it resolves to `client.X` (`wl_`), `xdg_shell.X` (`xdg_`) or falls back to `client.Proxy`. See `ifaceGoType` in scanner.go.

## Architecture

- `client/`: core runtime, hand-written: `context.go` (connection, object table, fd queue, id reuse), `event.go`/`request.go` (wire encoding), `common.go` (`Proxy`, `BaseProxy`), `display.go` (`Roundtrip`). `client.go` is generated from `wayland.xml` 1.25.
- `stable/`, `staging/`, `unstable/`: wayland-protocols 1.49. `wlr/`: wlroots protocols. `external/wayland-drm`: from mesa.
- `cursor/` and `cursor/xcursor/`: pure-Go port of wayland-cursor and xcursor. The README path `wayland/cursor` is stale, and `wayland/` is an empty dir.
- `internal/tempfile`: shm temp files. `examples/imageviewer` (window, cursor, keyboard) and `examples/idlenotifier` (the CI smoke test against headless sway).
- `test/tmp/`, `test/logs/`: gitignored scratch space for binaries, logs and helper scripts. Put temp files here, not in `/tmp`.

## Gotchas

- Directory names do not match package names, and a package name is not unique. For example, `staging/fraction-sclae-v1` (sic) is package `fractional_scale`. `tablet` exists in `stable/tablet`, `unstable/tablet-v1` and `unstable/tablet-v2`. `text_input`, `xdg_foreign` and `linux_dmabuf` also exist twice. Check `-pkg` in `doc.go`.
- Package names use underscores (`ext_idle_notify`, `wlr_layer_shell`), and lint deliberately disables ST1003. Don't "fix" them, and keep exported names and error strings stable (ST1005/ST1012 are off because they are public API).
- Concurrency contract (`client/context.go`): register, lookup and write are safe to call concurrently. Reading/dispatch must run on one goroutine. Requests that create objects must be serialized by the caller (ids must arrive in order).
- Received fds are queued and given to the event that carries them, based on the `FdEventer.FdEvents()` bitmask that generated proxies implement. Events for destroyed ids that are still awaiting `delete_id` are dropped and their fds closed. Client ids are reused LIFO after `delete_id`.
- `.gitattributes` still lists `wayland/...` paths for linguist-generated, which is stale.
- `examples/idlenotifier/v1/go.mod` is a leftover nested module (go 1.19). It is not part of the examples module.

## Testing

- Standard `testing`, no framework or external services. Wire tests fake the compositor with a unix socket: `unix.Socketpair` + `newContext` (`client/wire_test.go`, internal package) or `net.Listen("unix", …)` + `client.Connect(path)` (`unstable/text-input-v3/text_input_test.go`), then compare raw bytes.
- `client/context_test.go` holds `Example*` funcs with no `// Output:`. They only compile, and running them needs a real compositor.
- Lint excludes errcheck/staticcheck/unused in `_test.go` and `examples/`, and skips `test/` completely.
- Real-compositor check (CI, Linux): run sway with `WLR_BACKENDS=headless WLR_RENDERER=pixman`, then `WAYLAND_DISPLAY=$sock ./idlenotifier-bin`.
